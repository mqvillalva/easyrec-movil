# EasyRec para celular

Grabadora web para entrevistas y podcasts con el micrófono del celu (iPhone y Android): WAV y/o MP3, pausa, marcas,
medidor y lista para escuchar, guardar o compartir. Las grabaciones quedan en el celu; no se suben a ningún lado.
Ver `CLAUDE.md` para cómo está hecha.

- Probar en la compu: `npm install`, `node node_modules/electron/install.js`, `npm test`, `npm run smoke`, `npm run serve`.
